# .github

Plantillas por defecto de la organización `cortex-projects-org`. GitHub las aplica a todos los repos de la org que no
tengan plantillas propias. El repo es público porque GitHub lo exige para eso, y no tiene ningún dato de clientes.

## Cómo se usa

No hace falta hacer nada: al abrir un issue o un PR en cualquier repo de la org, GitHub ofrece estas plantillas. Los
issues siempre se crean con una plantilla, porque los issues en blanco están desactivados.

Para cambiar una plantilla en todos los repos, se edita acá y se hace un PR.
